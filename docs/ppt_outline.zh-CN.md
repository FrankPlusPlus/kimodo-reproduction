- **模型能力（简）：** 同一模型支持自然语言与多种运动学约束（全身关键帧、末端、root 路径/路点等），生成时序连续、语义正确的 3D 人体动作。

## 第二部分：论文原理——原文数据流讲透

> 相当于论文 pre。目标是让听众跟完一条完整数据流后，能独立画出“样本如何变成 \(\hat{x}_0\) 与 loss”。深度优先于广度；工程文件名、K8s、交付清单不进本部分。

### 第 3 页：论文在解决什么——形式化问题

- 输入：动作序列 \(x_0\)、文本条件、运动学约束（值 + mask）。
- 输出：满足语义与约束的 clean motion \(\hat{x}_0\)。
- 训练：对 \(x_0\) 加噪得 \(x_t\)，denoiser 直接预测 \(x_0\)（非 \(\epsilon\)）。
- 相对传统 text-to-motion：不仅“做什么”，还要“在哪里、何时、以什么姿态做”。
- 点明后文数据流主轴：表示 → 条件 → 扩散与约束注入 → Root/Body → 损失 → 两阶段课程 → 推理。

### 第 4 页：一张总图——训练时完整数据流

用**一张端到端图**串起（后续每页是此图的放大）：

1. 样本：motion + text embedding
2. 特征：旋转/root → 369 维 \(x_0\)，归一化
3. 条件：LLM2Vec 文本 + timestep + heading → 52 prefix
4. Phase 2：在线采样 observed motion / motion mask
5. 扩散：cosine schedule → \(x_t\)；约束覆盖 \(\tilde{x}_t = m\odot x_{target}+(1-m)\odot x_t\)
6. Root Transformer → global root (5) → local root (4)
7. Body Transformer → body (364) → 拼成 \(\hat{x}_0\) (369)
8. 七项损失 → 更新；EMA 积累推理权重

**口径：** 本页只建立地图；深度在后续页展开。

### 第 5 页：骨架、坐标系与 369 维动作表示

- SOMA 训练投影：30 关节；global / root-relative / heading 关系。
- 首帧 root XZ 归零、随机 heading augmentation 的目的。
- 369 维分块表：

| Feature block | 维数 | 含义 |
|---|---:|---|
| smooth root position | 3 | 平滑 root 全局位置 |
| global root heading | 2 | \((\cos\theta,\sin\theta)\) |
| local joint positions | 90 | 30 关节 root-relative 位置 |
| global 6D rotations | 180 | 30 关节全局 6D 旋转 |
| joint velocities | 90 | 30 关节全局速度 |
| foot contacts | 4 | 足接触 |
| **合计** | **369** | root 5 + body 364 |

- Root 输出 5 维 global；Body 侧 local root 为 \([\dot\theta,\dot p_x,\dot p_z,p_y]\) 共 4 维。
- 强调：模型预测的是这套特征，不是原始旋转矩阵本身；FK 在特征构建与几何 loss 中的角色。

**图示：** 原始 pose → FK/特征构造 → 369 维分块着色图。

### 第 6 页：文本条件与 52 个 conditioning prefix

- 三个向量来源：离线 LLM2Vec 句向量；扩散步索引 \(t\)；首帧朝向角 \(\theta\)。
- 文本 pad 到 50：1 真实 + 49 zero；`use_text_mask=false` 让 zero 当内部寄存器。
- timestep 图画：\(t\) 查同一张 sinusoidal PE 表第 \(t\) 行 → Linear→SiLU→Linear。推理查表画在推理循环页。
- heading 图画：\(\theta\to(\cos\theta,\sin\theta)\to\mathrm{Linear}(2\to 1024)\)。
- Root / Body 同类条件、参数不共享。

### 第 7 页：前向扩散——从逐步采样到一次加噪

- 主公式用等价采样，不把 \(\mathcal{N}(\cdot)\) 当主角：
  \(x_t=\sqrt{1-\beta_t}\,x_{t-1}+\sqrt{\beta_t}\,\varepsilon_{t-1}\)。
- 代入 \(t=2\)，独立高斯方差相加，得到
  \(x_2=\sqrt{\bar\alpha_2}\,x_0+\sqrt{1-\bar\alpha_2}\,\varepsilon\)。
- 归纳一次加噪：\(x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\varepsilon\)。
- 训练：抽 \(t,\varepsilon\)，一次算出 \(x_t\)；Denoiser 预测 \(\hat{x}_0\)（非 \(\varepsilon\)）。

### 第 8 页：运动学约束——表示、注入与 pattern

- 采样器输出同形 `observed_motion`、`motion_mask`。
- 覆盖公式：\(\tilde{x}_t=m\odot x_{target}+(1-m)\odot x_t\)；mask 拼到输入，告知“哪些维是已知约束”。
- mask 不是 loss mask：模型仍预测全部有效帧的 369 维。
- pattern：text-only、full-body keyframe、end-effector、root path、root waypoint；稀疏/稠密、单/双 pattern。
- 强调：约束值的坐标系、时间范围、feature slice 必须与 369 表示严格一致——这是后文“未公开细节”会打穿的点。

**图示：** 若干典型 pattern 的 mask 热力图（同一段 motion）。

### 第 9 页：Root Transformer——先预测全局轨迹

- 输入：imputed noisy motion 369 ∥ mask 369 → `[B,T,738]` → `Linear→1024`。
- +52 prefix → Root Transformer（16L / 8H / 1024 / FFN2048）。
- 丢弃 prefix 输出，`Linear→5` 得 global root。
- 要点：虽只出 5 维，但能看见完整 noisy body 与完整约束 mask，故可与身体/约束协调。

### 第 10 页：Global → Local 与 Body Transformer

- global root 反归一化 → 长度感知有限差分 → local root 4 维 → 按 local-root stats 再归一化。
- Body 输入：noisy/imputed body 364 ∥ local root 4 ∥ 完整 mask 369 → `[B,T,737]`。
- 独立 Body Transformer → `[B,T,364]`，与 root 5 维拼成 369。
- Body **不读** Root hidden state，只读最终 local root——两级结构如何解耦全局轨迹与局部姿态。
- **点到为止：** 训练默认对 local root detach；完整影响放到第三部分讲。

### 第 11 页：七项损失、梯度路由与两阶段课程

- 直接损失：valid-frame masked Smooth-L1；论文权重：
  - root pos 10 / root heading 2 / joint pos 10 / joint vel 3 / joint rot 10 / foot 4 / FK 5。
- 谁监督谁：root 两项 → Root；其余 + FK → Body；DDP 按全局有效帧归一化。
- Phase 1（0–500k）：text-only，mask=0，dropout=0.1；学文本→自然动作先验。
- Phase 2（500k–1M）：约 90% 带约束，网络 dropout=0；在先验上学习约束遵循。
- Phase 切换时 optimizer / EMA / step 连续。

**图示：** 损失→模块的梯度流向简图（detach 开/关可在下一部分展开）。

### 第 12 页：推理数据流（与训练对照收束）

- 噪声初始化 → 每步约束覆盖 → Root/Body → CFG → 多步去噪 → 反归一化 → 姿态/可视化。
- 与训练对照：同一套表示、同一套注入、同一两级结构；差别在多步采样与 CFG。
- **图画：** DDIM 10 步 \(999,888,\ldots,0\) 仍查同一张 PE 表，取出 1024 维再走 Linear→SiLU→Linear；不另建 timestep 词表。
- 本部分结束句：到此为止是**论文主数据流**；下一节进入“论文没写清、但会改训练效果”的细节。

## 第四部分：我们的做法与消融

> 讲“我们怎么训、改了什么、因果是否成立”。工程架构点到支撑训练即可，重点是实验设计与解读。

### 第 18 页：复现做法总览——闭环怎么搭

- 数据：公开资产 → canonical → feature/text cache → manifest/bundle。
- 模型：对齐公开 denoiser 的 checkpoint-sensitive 结构（prefix、两级、detach）。
- 训练：Phase 1/2 连续 1M step；BF16、Adam-atan2、EMA、可 resume。
- 评测：固定协议；主结论用分层 10% 官方子集（或最终全量），128 proxy 仅作趋势监控。
- 一句话边界：clean-room 重建 ≠ 官方 trainer 逐行复刻。

**图示：** 数据 / 模型 / 训练 / 评测四块闭环，标出“论文 / 代码 / 自研”颜色。

### 第 19 页：一次训练 step 的真实路径（做法锚点）

1. 读 manifest → motion + text cache  
2. collate padding → valid_frames / lengths  
3. text dropout；Phase 2 约束采样  
4. 加噪 → 约束覆盖 → mask 拼接  
5. Root → global-to-local →（detach）→ Body  
6. 七项 loss → DDP reduce → clip → step → EMA

## 第六部分：展望——方法谱系、历史方位与规划

### 第 28 页：动作生成方法谱系——我们站在哪

用一条清晰演进轴（按你们最终选用的分类微调），例如：

1. **运动学/检索与拼接时代：** 图搜索、运动图——可控但难语义泛化。  
2. **早期学习生成：** VAE / RNN 动作生成——有分布建模，控制弱。  
3. **Text-to-Motion 爆发：** TEMOS、MDM、T2M-GPT、MotionGPT 等——语义强，精确时空控制弱。  
4. **可控 / 约束运动生成：** 目标轨迹、关键帧、物理引导、两阶段或级联控制——Kimodo 所处位置：**扩散 + 统一文本与多类运动学约束的 kinematic motion diffusion**。  
5. **具身 / 机器人与策略数据：** 从动画资产走向可执行轨迹与仿真数据（与我们游戏/下游动作数据目标相接）。

**本页结论句：** Kimodo 不是“又一个 text-to-motion”，而是把**语义条件与运动学条件放进同一扩散去噪器**的路线；我们的工作是把这条路线从“可推理的公开权重”推进到“可训练、可改数据、可评测”的资产生产线。

### 第 29 页：相对谱系中相邻方法的取舍

简表对比（填你们真正对过的点，避免空泛点名）：

| 维度 | 纯 text-to-motion | 强物理/仿真控制 | Kimodo 路线（本复现） |
|---|---|---|---|
| 语义开放度 | 高 | 中低 | 高 |
| 时空/末端精确控制 | 弱 | 强 | 强（约束注入） |
| 训练与数据门槛 | 相对成熟 | 高 | 高（公开 recipe 不全） |
| 游戏动作生产适配 | 需后处理 | 重 | 直接对齐创作控制接口 |

- 诚实写短板：长序列、物理伪影、约束冲突、公开数据 vs RP 差距等。

## 5. PPT 制作规则

- 每页标题尽量直接表达结论，例如“Root/Body 两级建模把全局轨迹与局部动作解耦”，避免只写“模型介绍”。
- 一个页面只承载一个逻辑问题；内容多就拆页，不为控页数挤问题。
- **第二部分**统一配色：root / body / text / constraint / noise，全篇原理图一致；图上同时给语义与关键 tensor shape。
- **第三部分**每页必须出现“信息来源”标签（论文 / 公开代码 / 本仓库）。
- **第四部分**消融页必须写清评测资产与“不可外推”边界。
- **第五部分**结果页标明数据版本、checkpoint step、种子、推理参数、指标方向。
- 完成度只使用可核验状态：“代码存在”≠“训练完成”，“生成过样例”≠“效果复现”。
- 失败实验与官方未公开边界主动展示。
- 动态结果同时准备关键帧、输入约束和数值指标，避免视频与证据脱节。
- 第一部分保持短：业务价值说清即止，把时间留给数据流与消融。
