# Phase 2 训练坍塌消融历程（2026-08-14 → 2026-08-17）

本文按实验顺序记录 V2 1M hostnet 复现线在 Phase 2 中后期的坍塌、错误归因、对照实验和当前结论。每一轮都写成四段：**现象 → 当时的猜测 → 做法及其原理 → 结果**。后一轮会推翻前一轮的部分结论，所以不要只读最后一节。PPT 可直接用文首「汇报口径」和文末第 15 节。

**截至 2026-08-17 01:27 CST：** 没有还在健康训练的 1M 主线。发病路径探针已闭合：微分上损失仍惩罚翻脸；同一批上虚走 20 步，atan2 几乎不掉夹角，切断散度回传反而大掉。发病是跨许多 batch 的慢漂。可对外报的点仍是 **750k**。下一枪若训：从还没翻的 **50 万或 65 万** 加大衰减，不要垫最小散度、不要从 75 万加第八项损失。

评测协议与 `docs/ablation.zh-CN.md` 相同：`kimodo-benchmark-stratified-10pct`（paper protocol，100 diffusion steps）。下文质量数字默认 **content Overview**（约 92 段动作），约束数字默认 **Constraints with text**。那份文档记的是 benchmark / Core10 消融，和这次 **优化动力学坍塌** 不是同一件事。

### 汇报口径（做 PPT 用，只写已确定的）

1. **结构能训、课表能过 K=8/9，但这套复现配方在 Phase 2 中后期会把最后一层训成「对着干」。** 官方同结构到过 K=20，所以不是「16 层 post-norm 一定训不了」。
2. **696.6k 不是课表死点，但是同一条「抹掉」路的第一次发作。** 平滑 K、冻 K=7、换 seed、800 通道预算都在同一时刻抬梯度；`wd=0.3` 从 650k 分叉后过了 696.6k、进了 K=9。kf-smooth 695k（起飞前最后一份）最后一层夹角已是 **−0.10 / 80% 反向 / σ 仍 1.31**——和后来 wd03 的 750k 同形态。原线留下来的 690k 已经是 **−0.995 / σ 0.17**。wd=0.3 推迟了发病，没有换病。
3. **延迟家族已经穷尽，不能当产品方案。** 再降全局 LR、全局 clip、锁 K、skip-grad、换 seed 都不治。救援把峰值 LR 收到 3e-6：**起飞钟几乎没推迟，795k 文本已经坏掉。**
4. **当前最佳质量点是父 run 750k**（content Overview FID **0.116** / R@3 **98.9%**，打平或略优于 Official Overview FID 0.119）。800k 已退到 0.137 / 96.7%。不要用救援 795k 当分叉父本。
5. **爆炸当时的近因是最后一层残差对冲，不是抄关键帧、不是 LN 的 γ、不是权重谱爆炸。** post-norm 做 `x ← LN(x + attn(x))`：795k 夹角余弦 −0.52，800k −0.82；叠完变安静，LN 按安静程度放大回传。Adam-atan2 几乎不看「有多大」，于是棘轮。
6. **注意力对冲是训出来的；前馈对冲更早、而且健康时就已经有。** 400k/500k 最后一层注意力仍同向（约 +0.19）。平滑课表 650k / 690k 注意力仍 +0.23 / +0.22，**695k 翻到 −0.10**。同一套权重换约束时钟几乎不变。但最后一层**前馈**在 650k 已是 −0.52，690k −0.60，训练仍健康——前馈对着干不是 696k 那场病。
7. **800k 的大梯度就是这个除法造成的（实验 1 v2）。** 反传时把最后一层散度垫回 750k 水平（约 0.96），L15 注意力梯度 2615→938，回到 750k 的 956。第一次 STE 写错，`not_sigma` 作废。前向硬改已经死掉的 800k 权重会把损失搞崩，那不是训练时垫散度的有效对照。
8. **锁死之后损失离不开抹掉（实验 2）；发病当时损失并不发奖金（实验 O + P）。** 800k 剥掉注意力反向分量，损失 5.8×。690k 大步拨过零，损失 1.040×；微分 `d损失/dα = +0.007`，仍是惩罚更反向。所以不是目标在教它开始翻。
9. **发病是慢漂，不是单步 1/σ 或 atan2 独有的病。** 同一批虚走 20 步：atan2 夹角只掉 0.003；普通 Adam 掉得更多（0.013）；切断散度回传掉 0.14——发病阶段 1/σ 是刹车，不是油门。最小散度 / 末层 pre-norm 当发病药会更糟。20 步也测不出最后一层衰减（太短）。已证明能推迟发病的，仍是从还没翻的点加衰减。可对外报的点仍是 **750k**。

## 0. 怎么读、什么可以动

论文和发布去噪器已经钉死、主线消融里 **故意没改** 的：

- 两阶段 denoiser，`detach_root_for_body`
- post-norm Transformer，16 层 body
- 七项 loss；全身稀疏关键帧 **只贴位置和朝向**，同一帧旋转仍是扩散噪声
- loss **不按** constraint mask 屏蔽
- Phase 1 = 500k，Phase 2 dropout 0（论文写明）
- 课程最终 **Kmax → 20**
- 七项 loss 权重（论文写明）
- Adam-atan2 与 lr \(2\times10^{-5}\)（论文写明；λ、wd、clip、精度未写）
- V2 benchmark lane 0.25
- `copy-through` / 归一化 direct loss

论文没写死、这次实际在拧或补上的：`gradient_clip_norm=1`（论文未提；**健康段几乎不触发，不是学会抹掉的原因**）、Adam-atan2 的 λ=8、weight decay、是否重置 Adam、BF16、常数 lr、关键帧整数课表的形状、是否 skip 极大梯度、是否给稀疏通道加预算。官方同结构能训到 20 帧，所以目标始终是 **1→20 的复现**，不是把课程锁在 7。

日志口径：`train.jsonl` 每 20 个 optimizer step 记一次，数字是窗口均值。单窗 loss 在 0.21–0.29 之间晃是常态，**不是起飞**。真正要看的慢变量是：容易样本的 gnorm 中位数（文中称 **底板**）、clip 是否打满、后层 `body_layer_15_grad_norm`（L15）。

## 2. 轮次 A：原线坍塌（`v2-1m-hostnet`）

### 现象

Phase 1（0–500k）gnorm 在往下走，500k 是当时最好的 FID。Phase 2 按 `round(1+19p)` 把连续上限收成整数 Kmax。

- **644.7k–671.05k，Kmax=7：** loss 中位 ~0.24，gnorm 中位 ~0.60，clip=0，没有尖峰。
- **671,060 升到 Kmax=8：** 头 ~3k 步仍像 7。
- **~674k 起** clip 开始打满；680k–696k 多数窗口 `clip_fraction=1.0`，pre-clip ‖g‖ 从 0.6 爬到几十～两百，**loss 仍在 0.3–0.5**。
- 三次尖峰被拉回：689,920（loss 6.96）、690,020（9.95）、694,640（4.97，‖g‖ 到过 6129）。
- **696,780→696,800：** 20 步窗口里 loss 0.37→4.50，`joint_position` 0.0078→0.127，`foot_contact` 0.018→0.216，‖g‖ 24→885，随后 2200 / 6473 / 12641。loss 锁在 **~10.4**，一直到 721k 没回来。
- root 几乎不动；炸的是 body。没有 NaN（非有限会直接杀任务）。Kmax=9 是坍缩之后的 **697,380**，不是触发点。
- 700k 评测是坍缩后导出：content R@3 98.9%→1.1%，FID 0.13→1.97，full-body 8.9 cm→65 cm。**不能当质量点。** 最后健康完整评测是 **600k**。690k 当时还在，后来被 `keep_last=3` 轮换威胁，已拷到 `preserved-pre-collapse/`。

### 当时的猜测

最高置信度故事是：**7→8 的约束密度变化触发 Body 失稳，再被恒定 lr=2e-5 + Adam-atan2 + 全局 clip=1 放大。**

具体链条当时写成：

1. `round()` 让全体 rank 同一天从上限 7 变成 8，第一次出现 k=8。
2. 论文 \(k^{-1}\) 下 P(k≥7) 从 5.5% 升到 9.9%；V2 幂 0.45 更肥（9.9%→17.5%）。
3. 全身关键帧只钉位置，旋转仍是噪声；loss 不看 mask；FK 用预测旋转 + GT root。
4. clip=1 饱和后更新只剩方向；Adam-atan2 近似尺度不变，raw ‖g‖=10⁴ 不会把步子缩小。

排除过：BF16 溢出、DDP 归一化错误、「clip 没开」。也排除过「没贴旋转是实现漏了」——发布约束构建器本来就写 `global rotations are not used here`。

### 做法及其原理

没有在坏盆地（721k）上续训。保留 600k milestone，拷走 690k。下一步准备从 600k fork，而不是 Restart 16 卡任务。

### 结果

现场时间线是扎实的：**坍塌发生在 KF8 窗口内，约 2k 步后进入正反馈，约 25k 步后锁死。** 「7→8 是触发器」当时和日志对齐，但还没被对照实验证伪。这一轮 **没有** 证明：哪一个 NPZ、哪一种 pattern、20 步里是 1 步还是多步。日志只记「2048 条里多少条用了全身」，不记实际贴了几帧；种类占比在 KF8 前后几乎不变（~18.5%），和 gnorm 相关系数只有 ~0.03。

## 3. 轮次 B：平滑课表 + 学习率减半（`kf-smooth-lr1e5`）

### 现象

原线已经证明：在 lr=2e-5 下，Kmax=8 的窗口里会 clip 饱和然后锁死。K=7 的 26k 步是健康的。官方同结构能到 20，所以锁死 K=7 只能当对照，不能当产品方案。

### 当时的猜测

两件事叠在一起：

1. **`round()` 硬切** 让分布一天之内换档，二阶矩来不及适应。
2. **2e-5 太大**，clip 饱和后 Adam-atan2 仍走满步，把 body 推离流形。

平滑只能消「突然进入 8」，消不掉「待在 8」。真正扛进去之后别被推走的，被认为是 **LR 减半到 1e-5**。V2 lane 不关：占比在 7→8 没有突变，关 V2 等于一次替换约 1/4 约束分布。

### 做法及其原理

从 **600k** fork 到新目录 `runs/v2-1m-hostnet-kf-smooth-lr1e5`。

- `sparse_keyframe_cap_mode: adjacent_mix`：连续上限=7.3 则 70% 按 K≤7、30% 按 K≤8，最终仍到 20。
- Phase 2 峰值 lr **1e-5**（原来 2e-5）。
- V2=0.25、clip=1、位置-only paste、detach、Kmax=20 不动。
- checkpoint 改成每 5k、滚动留 20 个（覆盖 100k 步），避免再丢掉 650/660/670k。
- 启动：`exec bash …/company_start_hostnet_fork_600k.sh`。不要用 `company_start_hostnet_resume.sh`（那会接着坍缩的 720k）。

后来在这条线上还加过 skip-gradient、constant-load / 通道预算等「限制尾巴」的代码。那些是同一条 run 上的中途补丁，不是一开始的最小改动。

### 结果

**K=8 被证明确实可以健康学。** 671k–696k 大约 25k 步：loss ~0.23，‖g‖ ~0.5，clip≈0。650k 评测相对 600k 全身约束在收（约 8.85→6.47 cm），足滑和 FID 也在变好。

但 **~696.6k 再次起飞**：gnorm 中位 0.50→0.68→1.05，clip 开始灌满；loss 仍 0.23–0.27，**没有**再锁到 10。`adjacent_mix` 在 scheduled≈8.47 时已经把 cap=9 混到约一半，日志里的 `maximum_sparse_keyframes` 走的是 `round()`，当时还写着 8。skip 阈值后来收到 2，任务在 696.9k 附近因 skip 比例熔断。

695k 分层 10% 对 Official SEED-v1（content with-text）：

| 指标 | Official v1 | kf-smooth 695k |
|---|---:|---:|
| Overview FID | 0.119 | **0.119** |
| 全身位置 | 4.01 cm | 5.51 cm |
| 末端位置 EE | 4.86 cm | **11.00 cm**（约 2.3×） |
| 末端旋转 | 6.8° | 12.0° |
| skate | — | 六个桶都差 +0.2–0.7 cm/s |

650→695 仍是健康的 Phase 2 收紧（EE 大约 −1.1–1.5 cm）。FID 打平官方，**约束精度还欠一截**。695k 是质量点，不是 1M 主线终点。

这一轮证伪了「8 是容量墙」。留下的新问题：为什么 **同一时钟 696.6k** 还会抬 gnorm？

## 4. 轮次 C：800 通道预算（`cap800-from695k`）

### 现象

kf-smooth 在打开 cap=9 的尾巴时 gnorm 爬升。平均关键帧一直约 2.3，全身比例约 18.5%，和梯度几乎不相关。有人猜测是「9 帧全身 / 多约束叠满」这种超预算针。

### 当时的猜测

把稀疏通道总负载卡在 800 个 feature 单位：先付 EE，剩下的钱再抽全身；9 帧全身会被收成 8。平均负载从来不是问题，800 挡的是尾巴。skip=2 挡住已经数值垃圾的一步。

### 做法及其原理

从 **695k** fork 到 `v2-1m-hostnet-cap800-from695k`。overlay 后来写进了 `v2_1m_from600k_kf_smooth.yaml`（文件名仍叫 from600k，实际这次父本是 695k）。启动脚本 `company_start_hostnet_fork_695k.sh`。

原理：限制 **mask 里能写多少维**，不改变论文五种约束的含义，也不关 V2。

### 结果

约 1.9k 步（695k→696.9k）：

| | 开训 | 停下 |
|---|---|---|
| 稀疏负载均值 | ~102 / 800 | ~103 / 800 |
| 平均关键帧 | ~2.8 | ~2.8 |
| 全身比例 | ~0.18 | ~0.18 |
| gnorm 中位 | 0.53 | **1.14**，clip 80–90% |

平均被勒住了，**曲线还是同一条。** 原线在纯 K=8、没有 9 时就已经炸；800 把 9 帧全身砍成 8，起飞钟不变。loss 仍 0.23–0.30，爆炸被压住，但不是稳态。

**结论：800 和均值负载都对不上 696.6k。** 这一枪后来被明确标成回避 / theater，主线不再用。

## 5. 轮次 D：冻采样上限=7（`k7-from690k` / `k7-from695k`）

### 现象

C 之后，日志能证明的只剩：‖g‖ 跟的是 **step**，不是 k / load / FB 占比。`corr(‖g‖, k/load/cap/FB) ≈ 0`。还没被证伪的只剩两层：20 步均值把针平均掉了；或者 **权重自己在变锐**，clip+Adam-atan2 只是过 1 之后的伴随。

### 当时的猜测

如果右端 k=8/9 的针是因，把 **采样 support 冻在 7** 应该让 696.6k 的 gnorm 停在 ~0.55。课表数字仍按 1→20 走（695k 的 scheduled 仍 ~8.4），只是抽的时候不许超过 7 帧。不要写 `sparse_keyframes_max: 7`，那会把整段 1→20 重新缩放，695k 的 scheduled 会从 8.4 掉到 ~3.3。

从 690k 而不是 695k fork：Adam m/v 的记忆只有几百～几千步，690 和 695 的动量几乎是两套新的；差的是 **权重多走了 5k 步**。若 695k 已经在漂，690k 多 6.6k 步跑道。

### 做法及其原理

- overlay：`configs/overlays/v2_1m_k7_from695k.yaml`
- `sparse_keyframes_hard_cap: 7`，`sparse_channel_budget: 0`（不和 800 搅在一起）
- lr 仍 1e-5，skip=5
- 启动：`company_start_hostnet_fork_690k_k7.sh` 或 `_695k_k7.sh`
- 看 `sampled_sparse_keyframe_cap_mean` 应是 **7.0**，`scheduled_sparse_keyframes` 仍 ~8.4

### 结果

**采样冻在 7，696.6k 照样起飞。** 这直接证伪了「这一时刻是因为 batch 里出现了 8/9 帧针」。696.6k 不是课表数字 8 或 9 的物理墙。

## 7. 轮次 F：只读探针（FK/6D 与 body Jacobian）

训练对照已经把采样、800、seed 拿掉。剩下要分清：梯度涨是因为 **对预测更敏感**（loss / FK / 6D 奇点），还是因为 **参数空间里网络自己更放大**。

### 7.1 FK / 6D Gram-Schmidt

**猜测：** 6D 旋转两列平行时 Gram-Schmidt 奇异，FK 把极大梯度打进 body。

**做法：** `scripts/diagnose_fk_6d_grads.py`。固定 batch，对 650k / 690k / 696k 只做前向和「对预测」的反传，不更新权重。看 6D 列范数尾巴、叉积尾巴、以及各 loss 项的 \(dL/d\hat{y}\)。

**结果：** 各 loss 项对预测的梯度是平的。FK 的 \(dL/d(6D)\) 没有单独恶化。**不是 FK/6D 奇点。** 训练 jsonl 里涨的 ‖g‖ 来自 \(d\hat{y}/d\theta\)（body Jacobian），不是 \(dL/d\hat{y}\)。

### 7.2 body Jacobian：后层增益 vs batch 对齐

**猜测有两种：**

1. 同一 batch 里各样本的参数梯度突然同向，平均后不再对消。
2. 后层（尤其 LayerNorm）增益变大，同样的输出误差在参数上显得更大。

**做法：** `kimodo/training/body_jacobian_probe.py` + `scripts/company_run_body_jacobian_probe.sh`。冻结 4 条样本，对 650k / 690k / 696k 做 dropout=0 的训练态前向+反传。两趟约束：按 690k 采（K≈8）和按 650k 采（K≤7）。盘上结果：

- `…/diagnostics/body-jacobian-650-690-696/probe.json`
- `…/diagnostics/body-jacobian-650-690-696-k7/probe.json`

**结果（两趟一样）：**

- \(dL/d\hat{x}\) 没涨，还略降（约 0.94–0.99×）。
- batch 内 **没有更同向**：平均夹角约 88–89°，对齐比从 0.78 降到 0.57。
- 相对 650k，696k 的 **body 第 15 层参数梯度约 1.31×**，**第 14 层 LayerNorm 输入方差约 1.53×**。前面十几层梯度反而更小。

N=4 不能解释 jsonl 里全局 ‖g‖ 0.5→3 的全部幅度（这 4 条上 body 总梯度甚至在变小，650k 有一条野点把基线抬高了）。但它足够否定「预测空间变尖」和「样本对齐」，并指向 **late-layer gain**。

Phase 1 的 gnorm 是下降的，500k FID 最好，所以也不是「Phase 1 已经把网训尖了」。锐度是 **Phase 2 中后期** 自己长出来的。

## 8. 轮次 G：650k 起 wd=0.3（推迟了 696.6k，没有治好）

### 现象

到 F 为止，696.6k 最像：**Phase 2 把 body 后层（尤其 LN 尺度）训尖 → Adam-atan2 步长不随梯度缩小 → 全局 clip 一饱和只剩方向 → 底板被抬走。** 采样、K、800、seed、FK 都不是因。

父线 wd=0。论文没披露 weight decay；本仓库复现默认也是 0。

### 当时的猜测

## 11d. 轮次 M：对照论文（2026-08-17）

技术报告 Sec. 4.3：稳训只写了 Adam-atan2 和 lr \(2\times10^{-5}\)。没有 clip、没有 λ、没有 weight decay、没有精度。第二阶段去掉 dropout 是论文写明的。两级「端到端」在文里，发布代码和我们默认是 root→body detach。

`scripts/company_run_body_residual_cancel_probe_kfsmooth_690_695.sh`。同一套残差对冲探针、同一冻结噪声（seed 20260816，4 条）。权重：kf-smooth **650k / 690k / 695k**，再加原线 `preserved-pre-collapse/v2-1m-hostnet/step-000690000.pt`。约束时钟 **650000** 和 **695000**。盘上：`diagnostics/body-residual-cancel-kfsmooth-690-695/`。注意：kf-smooth 690k 和原线 690k 的 `global_step` 相同，partial 文件被后者覆盖；`verdict.json` 的 timeline 仍有 8 行。

### 结果（L15，两个时钟几乎一样）

| 权重 | 夹角余弦 | 反向 token | LN σ | 对应后来的哪一段 |
|---|---:|---:|---:|---|
| kf-smooth 650k | +0.23 | 25% | 1.39 | 健康同向 |
| kf-smooth 690k | +0.22 | 2% | 1.44 | 仍同向 |
| kf-smooth **695k** | **−0.10** | **80%** | 1.31 | **= wd03 750k**（刚翻脸，σ 未塌） |

### 结论

696.6k 和 750k 后是同一条「最后一层对着干」的路。原线约 690k 已经抹完并在 696.8k 锁死；平滑课表推到 695k 刚翻、696.6k 抬梯度；wd=0.3 再推到 750k 翻、800k 锁死。从 750k 再加大衰减，赌的是再推迟一次，不是新机制。

## 11f. 轮次 O：发病时拨动夹角看损失（2026-08-17 00:53）

### 现象

实验 2 证明 **800k 已经锁死之后**，剥掉反向分量损失会炸。那回答不了：69 万还没翻的时候，七项损失有没有在发奖金。

### 做法

`scripts/company_run_body_onset_nudge_probe_kfsmooth.sh`。冻结权重和同一批噪声（seed 20260816，4 条，时钟 695000）。把最后一层注意力或前馈的 token 夹角拨 **±0.25**，保持分支长度。权重：kf-smooth **650k / 690k / 695k**。盘上：`diagnostics/body-onset-nudge-kfsmooth-690-695/`。

拨动落点：690k 注意力 +0.22 → 更反向 **−0.03** / 更同向 **+0.47**。

### 结果（总损失相对原样）

| 权重 | 注意力更反向 | 注意力更同向 | 前馈更反向 | 前馈更同向 | 注意力判定 |
|---|---:|---:|---:|---:|---|
| 650k | 1.025× | 1.085× | 1.034× | 1.007× | 怎么拨都伤 |
| **690k（翻前）** | **1.040×** | **1.086×** | **1.091×** | 1.016× | **原样最低** |
| 695k（刚翻） | 1.073× | 1.079× | 1.145× | 1.022× | 原样仍最低 |

前馈在 650k 已是余弦 **−0.52**，690k **−0.60**；再往更反向拨，脚接触项 1.48×～1.73×。注意力翻号才是 696k 的病；前馈对着干更早，而且当时训练仍健康。

### 结论

发病时七项损失**不给翻脸发奖金**。原样就是局部最低。更反向会升损失，所以不是目标函数在教它抹掉。锁死（实验 2）和发病（实验 O）不是同一句话。单步 1/σ 油门被实验 P 否定，见下节。

因此：从 75 万加第八项「不许对着干」对不上发病机制。论文范围里更像还没试够的，是从**还没翻的点**（50 万 / 65 万）加大最后一层衰减。实验 P 把「单步 1/σ 油门」这条否了。

## 11g. 轮次 P：微分斜率 + 虚走 20 步（2026-08-17 01:27）

### 现象

实验 O 的 ±0.25 太大。还分不清：很小的一步损失是不是其实在奖励翻脸；以及 atan2、1/σ 回传、最后一层衰减，哪一个在推进夹角。

### 做法

`scripts/company_run_body_onset_path_probe_kfsmooth.sh`。同一冻结 batch（seed 20260816，4 条，时钟 695000）。权重 kf-smooth **650k / 690k / 695k**。

- P：α=0 处混向完全反向，读 `d损失/dα`（训练用的 frame-sum，再除以有效帧数）。
- Q：内存里走 20 步再还原。对照：Adam-atan2、反传切断 σ、普通 Adam、最后一层 wd=1。学习率按配置 1e-5。不写盘。

盘上：`diagnostics/body-onset-path-kfsmooth-690-695/`。

### 结果（690k 为主）

| 测量 | 数字 | 读法 |
|---|---|---|
| 注意力 `d损失/dα` | **+0.0074** | 微分上也在惩罚更反向 |
| 前馈 `d损失/dα` | −0.0035 | 低于阈值，算平 |
| atan2 20 步夹角 | +0.223 → +0.220（**−0.003**） | 几乎不动；损失 0.46→0.12，靠过拟合这批，不必翻脸 |
| 普通 Adam 20 步 | **−0.013** | 比 atan2 掉得更多 |
| 切断 σ 回传 20 步 | **−0.138**（到 +0.086） | 发病阶段 1/σ 是刹车 |
| 最后一层 wd=1、20 步 | −0.003 | 与 atan2 重合；20×1e-5 的衰减太小，测不出长期 wd |

650k 上 atan2 20 步掉 0.020；695k 已翻（−0.094）后 atan2/Adam 都停在附近，只有切断 σ 继续往 −0.22 推。

### 结论

自动判定 **`slow_multibatch_drift` / `stronger_wd_from_500_or_650`**。发病不是这一批上的一步油门。不要用最小散度或末层 pre-norm 当发病药——切断 σ 会加速翻脸。不要因为 20 步看不出，就否定几万步的最后一层衰减：0.3 从 650k 已经把发病从 ~695k 推到 ~750k。1/σ 放大梯度是**锁死阶段**（实验 1）的事，不是翻号的起点。

## 12. 串起来的机制（近因 + 损失偏好已测；clip 是假说）

**已确定的近因链（795→800，时间线把它的起点钉在 750k）：**

最后一层学会让 `attn(x)` 对准 −`x` → `x+attn(x)` 变安静 → post-norm LayerNorm 除以小 σ → 回传变大（实验 1：垫除数后 L15 梯度回到 750k）→ Adam-atan2 不收步、**我们补的** 全局 clip=1 饱和后只剩方向 → 底板抬升 / 锁死。

**损失侧：**

- **锁死之后**（实验 2，800k）：剥掉注意力反向分量，损失 5.8×。已经靠抹掉压损失。
- **发病当时**（实验 O/P，690k）：大步拨过零损失 1.040×；微分 `d损失/dα = +0.007`。七项损失不是翻脸的老师。
- **发病虚走**（实验 P）：同一批 20 步，atan2 夹角几乎不动；切断 σ 回传反而大掉。1/σ 是锁死阶段的放大器，不是翻号的起点。

只垫散度可能挡住后来的梯度爆炸，挡不住质量先坏（救援 795k 已经是这样）。加第八项「不许对着干」对不上发病：当时损失已经不喜欢更反向。

**仍是假说、不能再写成下一刀的：**

论文用 Adam-atan2 本身当稳训，没写 clip。但健康训练里 clip 几乎不触发；它是梯度已经爆了之后才饱和。拿掉 clip 改变的是「歪了以后优化器怎么走」，**改变不了 750k 起学会抹掉、质量先掉**。不当根因实验。

末层 pre-norm、加第八项损失都能改变学习问题，但都不是论文配方，不当默认续训。第二阶段去掉 dropout 是论文写明的，不是偏差。

这 **不是** 已经测过的 edge of stability（没算 Hessian）。也 **不是**「再降 LR 就能过 1M」。也 **不是**「拿掉 clip 就能过 800k」。
